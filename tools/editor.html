Never paste this token into a chat, email or message — not even to me. It goes in the box below and nowhere else. It's kept in this browser only, and "Sign out" erases it.

  1. Open github.com/settings/personal-access-tokens/new (log in if asked).
  2. Token name: anything, e.g. site editor
  3. Expiration: your choice. Longer means fewer interruptions; 90 days is a sensible balance.
  4. Repository access: choose Only select repositories, then pick kay-quan.github.io. This is what keeps the token harmless — it can't touch anything else you own.
  5. Permissions → Repository permissions → Contents: set to Read and write. Leave everything else alone.
  6. Click Generate token, copy it, paste it below.
